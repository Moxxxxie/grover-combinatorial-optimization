# Grover Combinatorial Optimization

A collection of quantum computing implementations that use Grover's Algorithm
to solve combinatorial search and constraint satisfaction problems.

## Problems Covered

- [ ] Grover basics
- [ ] Oracle construction framework
- [ ] 3-SAT implementation
- [x] Graph coloring implementation
- [ ] Graph Tessellation
- [ ] N-Queens implementation
- [ ] Performance analysis
- [ ] Final report

## Objectives

- Study Grover's Algorithm in practical settings
- Construct problem-specific quantum oracles
- Compare theoretical and experimental performance
- Provide reproducible implementations in Google Colab

## Technologies

- Python
- Qiskit
- NumPy
- Matplotlib

## Repository Structure

```text
notebooks/   -> Interactive demonstrations
src/         -> Reusable implementations
docs/        -> Reports and references
figures/     -> Generated figures
```

## Installation

```bash
pip install -r requirements.txt
```

## Running

Open any notebook from the notebooks directory in Google Colab.
